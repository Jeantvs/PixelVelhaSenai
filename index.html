FALTA CONFIGURAR O FIREBASE

  1. Acesse console.firebase.google.com e crie um projeto (grátis).
  2. Em Realtime Database, clique em Criar banco de dados e escolha modo de teste.
  3. Em Configurações do projeto → Seus apps, adicione um app Web (</>) e copie o firebaseConfig.
  4. Abra este index.html num editor e cole no lugar de FIREBASE_CONFIG, no topo do arquivo.
